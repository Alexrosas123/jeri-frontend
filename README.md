# jeri-frontend

Front-end del **Sistema Integral de Gestión para Comercializadora MEDIDENTAL JERI S.A. de C.V.**

Hecho con **React + Vite** y CSS normal (un archivo de estilos por componente).
Diseño de referencia en Figma: https://www.figma.com/design/Ers1oxsks6TMnhkUB5U0cF


### Conexión con el back-end

Por ahora el login funciona en **modo simulación**: con cualquier correo válido y una contraseña de 6 caracteres o más, entra al sistema.
